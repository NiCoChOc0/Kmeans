# KMeans
## Run the ipynb file
On most distribution:
Install the python lib in `requirements.txt` and run a jupiter lab.

On NixOS:
```sh
./run.sh
```
Then open the jupiter lab link displayed (take a bit long the first time because the packages needs to be installed)

Tested on NixOS:
- Python 3.13.12
- numpy==2.3.4
- scipy==1.16.3
- skimage==0.25.2
